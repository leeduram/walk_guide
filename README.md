# 보행 도우미 (walk_guide)

LiDAR·초음파 없이 **스마트폰 카메라 한 대**로 점자블록·사람·장애물을 실시간 탐지(YOLO 이미지 디텍션)하는 보행 보조 앱입니다.

## 실행 (APK 설치 방식)

1. Android Studio에서 `pubspec.yaml` 화면 위의 **Pub get** (패키지가 바뀐 업데이트 때만 필요).
2. APK 만들기: 메뉴 **Build → Flutter → Build APK**, 또는 하단 Terminal에서
   ```
   flutter build apk --release
   ```
3. 결과 파일: `build\app\outputs\flutter-apk\app-release.apk` → 폰으로 옮겨 설치 (기존 앱은 먼저 삭제).
4. 처음 실행 시 카메라 권한 허용. 화면에는 글자를 띄우지 않으므로, 새 APK 설치 여부는 휴대폰 **설정 → 애플리케이션 → 보행 도우미** 의 버전으로 확인하세요.

- 학습 모델(`assets/models/walk_guide.tflite`)이 없으면 APK에 포함된 **기본 COCO 모델**(`yolo26n_coco.tflite`)을 씁니다.
  인터넷이 필요 없고, 사람·자동차·자전거 등은 잡지만 점자블록은 못 잡습니다. 학습 방법은 `training/README.md`.
- 앱이 켜져 있는 동안 화면 밝기는 최대로 고정됩니다 (`MainActivity.kt`, 앱을 나가면 원래 밝기).
- 저시력 사용자용이라 설정 화면·상태 표시(FPS 등)·글자 라벨이 없습니다. 값은 `lib/core/settings.dart` 의 기본값을 그대로 씁니다.
- 음성 mp3는 `assets/audio/` 에 넣으세요: `obstacle_on_path.mp3`(경로에 장애물이 있습니다), `braille_lost.mp3`(점자블록이 끊겼습니다), `crosswalk.mp3`(횡단보도입니다), `signal_red.mp3`(빨간불입니다), `signal_green.mp3`(초록불입니다), 없는 파일은 진동만 나옵니다.

## 동작 규칙

| # | 기능 | 구현 |
|---|---|---|
| 1 | RoI 필터링 | 화면 가로 25~75% 띠(세로 전체) 안의 사람·장애물만 경고 대상. 최대 인식 거리(기본 5m)보다 멀면 제외. 화면에는 3m 이내(위험)인 것만 빨간 박스로 표시 |
| 2 | 센서 없는 거리 추정 | 폰 기울기(가속도계) + 카메라 높이 + 박스 하단 위치로 지면까지 거리 계산. 3m 이내 또는 화면 15% 이상이면 위험(빨간 깜빡임). 가까울수록·빨리 다가올수록(접근 시간) 비프 주기 단축. 비프는 별도 타이머·네이티브 재생으로 영상 처리와 분리 |
| 3 | 점자블록 하이라이트 | 모델이 점자블록을 위아래 조각으로 탐지 → 조각은 프레임 사이에서 부드럽게 보정(`braille_smoother.dart`: 흔들림·한 프레임 깜빡임 제거)한 뒤, 이어지는 조각끼리 묶어 진한(85%) 형광 노란색 곡선 띠로 표시 (`lib/logic/braille_path.dart`). 화면 하단(가로 전체, 테두리 없음)에는 발에서 가장 가까운 점자블록 하나의 좌우 위치에만 노란 네모 1개. 점자블록이 화면에서 벗어나도 자이로로 방향을 기억해 그 방향(화면 밖이면 왼쪽/오른쪽 끝)에 네모가 남고, 5초 후부터 흐려져 8초에 사라짐. 그 방향을 다시 봤는데 점자블록이 없으면(끊김) 1초 후 바로 사라짐 (`lib/logic/braille_marker.dart`) |
| 4 | 경로 장애물 / 끊김 안내 | 위험 장애물이 점자블록 박스와 겹치면(장애물 기준 겹침 5% 이상 또는 발 위치가 블록 안) "경로에 장애물이 있습니다". 발밑 영역(하단 15%, 가로 전체)에서 점자블록을 따라가다 1.5초 이상 안 보이면 "점자블록이 감지되지 않습니다" (사람·장애물이 가리고 있을 때는 보류). 각 안내는 쿨다운 적용 |
| 6 | 횡단보도 | 화면 아래쪽(가로 10~90%, 아래 60%)에 횡단보도가 0.5초 보이면 "횡단보도입니다" (20초 쿨다운) |
| 7 | 신호등 | 보행자 신호등(세로형만 학습)이 가운데쪽에 3프레임 연속 같은 색이면 "빨간불/초록불입니다", 색이 바뀔 때마다 다시(10초 동안 안 보이면 초기화). 화면 맨 위에 빨강/초록 네모 |
| 9 | 훼손된 점자블록 | 주황색 띠로 표시 (안내 규칙은 일반 점자블록과 같음) |
| 10 | 볼라드 | 따로 학습해 인식률을 높이고, 앱에서는 일반 장애물과 똑같이 처리 |

## 거리 보정

설정 화면이 없으므로 카메라 높이(기본 1.3m)·기울기 보정 값은 `lib/core/settings.dart` 의 기본값을 바꿔서 조정합니다.

## 폴더

```
lib/
  core/      settings, types(클래스 매핑), geometry(좌표 변환·거리 계산)
  logic/     guide_engine.dart  ← 1~4번 규칙 전부 (위젯과 분리, test/ 에서 단위 테스트)
  audio/     audio_service.dart ← 비동기 비프 / 음성 우선순위 큐
  ui/        guide_screen.dart, overlay_painter.dart
assets/      audio/beep.wav, models/
training/    AI Hub 라벨 변환 → 학습 → tflite 변환 스크립트
```
